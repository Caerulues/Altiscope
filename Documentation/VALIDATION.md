# 验证记录

验证日期：2026-09-27。环境：macOS、Xcode 26.3、iPhone 16e / iOS 26.3 模拟器。所有模拟位置均为测试输入，不是真实行程。

## 已通过

- Swift 核心测试 **8 项，0 失败** ：距离与跨日期变更线、无效和陈旧定位过滤、暂停计时和分段、信号缺口、低速步行累计、截断日志恢复、未知测量值、长轨迹显示抽样。
- iPhone 模拟器 Debug 编译成功，Google 原生适配代码实际参与编译。
- iPhone 设备目标 Debug / Release 编译成功；Google Maps 11.2.0、MAMapKit 11.1.200、AMapFoundationKit 1.8.7 原生依赖实际链接。Release 未签名。
- 实际运行检查：示例轨迹、离线画布、Apple 底图、轨迹叠加、海拔与速度图切换、地图来源选择。
- 模拟器记录流程：定位权限、开始、暂停、继续、结束、名称修改、本地持久化。检查了落盘日志中的 **2 个点和 2 段轨迹** ，暂停前后的距离没有跨段相连。
- 旧定位失效后，实时数据转为缺失标记，页面显示等待 GPS。
- 最终画面中主记录操作固定在底部。真实模拟器截图见 `Previews/iphone-map.png`。

## 尚未验证

- 没有实际 iPhone 硬件测试：指南针、去重力加速度、锁屏和长时间后台 GPS、耗电、磁干扰和真实定位误差。
- 没有提供高德或 Google API Key，故未验证二者的在线鉴权、计费配置、卫星图和真实底图加载。
- 未开通高德高阶离线服务，未下载城市包，也未验证其断网加载。
- GPX / JSON 文件生成由同一导出实现校验；系统分享面板的完整人工操作未完成验收。
- 未签名安装到真实 iPhone，未发布 App Store。

## 构建说明

沙盒内调用 Xcode 会输出 CoreSimulator 访问告警。Release 资源编译需要访问 Xcode 服务，已使用获准的本地构建重试成功。高德 SDK 自带的 umbrella header 有 3 条警告，未修改第三方头文件；不影响编译通过。

验收范围只覆盖上面列出的场景，不等同于长期实机稳定性验证。应用首次启动不创建真实记录；点击「浏览示例轨迹」的数据单独标记，不写入旅程日志。
