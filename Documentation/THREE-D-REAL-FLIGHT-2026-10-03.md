# 真实航线三维显示修正（2026-10-03）

## 复现事实

使用用户指定的本机 JSON，通过应用的 `TrackImport.read` 和 `TrackDocument.session()` 读取并在隔离模拟器中展示；原文件未改动，未把私人轨迹加入仓库。

- 6,297 个定位点、17 段，最高海拔 11,171.7285 m，最低 -33.2249 m；高度基准为 MSL。显示抽样后生成 4,365 个有效高度顶点及 4,362 条边，分段未被跨越。
- iPad / iOS 18.6：全览时主线与零平面间距很小，放大后可以看到真实高度主线和半透明幕帘。几何并未缺失。
- iPhone / iOS 26.3：该航线全览时实际 MapKit 相机倾角为 0°，旧界面仍标为 3D。此为本次模拟器观测，不推定所有系统和缩放级别都相同。
- 旧全览调整只会拉远，而且在轨迹已落入安全区时立即停止，即使只占可用区域的一小部分；纯平移也强制至少再拉远 8%。

## 修正行为

- 全览适配同时考虑高处主线与零平面投影，允许放大过小的航线；只需平移时不强制缩小。进入三维时不再与倾角动画争抢相机。
- 系统把相机倾角限制在接近俯视时，进入三维改为查看高处航段的局部倾斜视图，并标明“3D 局部”。全览按钮仍显示整条航线；若此时系统限制倾角，明确提示“俯视全览”。
- 按后续界面要求移除高度倍率菜单，固定真实比例 ×1；颜色和点选海拔使用真实值。坐标、原始高度、导出数据及分段不变。统计与地图点选海拔共用的单位切换移至设置页，继续使用原有持久化偏好；公制为海拔 m、地速 km/h，航空单位为 ft / kts。
- 几何、投影与数据缺失的既有保护保留；本改动不是地形模型或航空导航能力。

## 验证与边界

- 44 项核心回归测试通过，另有 1 项仅在本机运行的真实文件验证通过；本机文件测试不进入仓库。
- 模拟器 Debug 与未签名设备 Release 构建通过。
- 实际检查 iPad iOS 18.6 及 iPhone iOS 26.3 的真实航线显示；iPhone 在 ×1 局部视图可见离地主线和幕帘，全览入口可用。
- 临时诊断日志、环境变量导入入口、私人文件和本地测试路径不写入正式源码。没有安装到实体手机、提交 Git 或发布版本。
